# SnapLite

A free, lightweight Windows screenshot app by Delta Computers.

**[Download the single Windows installer](https://github.com/raghebdcc/SnapLite/releases/latest/download/SnapLite-Setup.exe)**

**[Delta Computers download page](https://deltacomputer.co.il/downloads.php)**

## Features

- Press **Print Screen** and drag to select a screen area.
- Add arrows, pen strokes, rectangles, text and highlights.
- Cover sensitive information with an opaque black rectangle.
- Copy with **Ctrl+C**, save with **Ctrl+S**, undo with **Ctrl+Z**.
- Quick-save PNG files to **Pictures/SnapLite**.
- Hebrew interface; startup with Windows is selected by default and can be disabled during setup.
- No account, ads or screenshot uploads. Captures stay on your computer.

## Installation

Download `SnapLite-Setup.exe`, run it and follow the setup steps. The installer is complete and does not download extra packages. Windows 10/11 with .NET Framework 4.8 is required. The app installs for the current user without administrator rights.

The installer is currently unsigned. Windows may show an unknown publisher warning.

## Updates

Use **עדכונים וגרסאות** in the tray menu to open the latest release page. Install the newer version over the current one; saved screenshots are preserved. Updates are user initiated; this version has no automatic background updater.
